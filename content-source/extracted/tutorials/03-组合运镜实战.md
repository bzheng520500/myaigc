# 组合运镜实战：从静态画面到动态演变的两阶段工作流

单一镜头描述只能生成"一段运动"，而电影感来自**画面设计与镜头演进的组合**。本篇整理自《组合运镜》《组合运镜 2》两份中英对照提示词集，核心是一套两阶段工作流。

## 一、两阶段工作流

### 阶段 1：文生图（Text-to-Image）——先定"起幅画面"

用静态画面提示词生成一张构图、光线、景深都到位的底图。要点：

- **景别 + 角度**先行（Medium shot / Low angle / Dutch angle / Overhead shot……）
- **光线氛围**跟上（dramatic sunset lighting / backlight / side lighting……）
- **景深**明确（shallow depth of field / deep depth of field），它决定了画面焦点落在哪里

示例（仰拍英雄战士·中景）：

> Medium shot, low angle, looking up at a heroic warrior holding a sword, dramatic sunset lighting, shallow depth of field, cinematic.
> （中景，仰视一位手持长剑的英雄战士，戏剧性的日落光线，浅景深，电影感。）

### 阶段 2：图生视频（Image-to-Video）——再演"镜头运动"

以阶段 1 的画面为输入图，用运动提示词驱动镜头。写法公式：**运镜动词 + 主体变化 + 情绪收尾**。

示例（推近战士坚毅面庞）：

> (输入：英雄战士中景仰视图) Slow push-in on the warrior's determined face, wind blowing through his hair.
> （缓慢推进到战士坚毅的脸部，风吹动他的头发。）

常用运动词汇：Slow push-in（缓推）/ pull-out（拉出）/ tilt up（上摇）/ orbit around（环绕）/ crane shot（升降）/ handheld tracking（手持跟拍）/ whip pan（甩镜）。

## 二、五大叙事场景模板

《组合运镜 2》按叙事功能给出五组"静态 + 动态"成对模板，可直接套用：

1. **悬疑开场**：静态用极度特写 + 荷兰角 + 戏剧侧光制造不安；动态用颤抖拉出，揭示环境中的震惊面孔。
2. **英雄登场**：静态用逆光 + 仰角 + 尘土盘旋营造宏伟；动态用升降镜头上升环绕，展现废墟全景。
3. **发现与揭示**：静态用过肩镜头 + 手电光束划破深影；动态用稳稳推进，让神秘物体发出脉动光芒、焦点转移。
4. **宁静中的威胁**：静态用俯角广角田园村庄 + 地平线风暴云暗示厄运；动态用平滑推近后急速下摇，揭示通往森林的足迹。
5. **亲密与疏离**：静态用分像镜（一半清晰一半失焦）传达情感距离；动态用焦点转移 + 横移环绕打破分像效果，人物走入人群。

每组模板均为一条英文静态提示 + 一条英文动态提示，完整中英对照文本见提示词库「组合运镜」分类（共 25 条）。

## 三、五种高阶动态组合技

当单一起止不够用时，可用"一镜多动作"的组合描述：

1. **追逐场景**：手持跟拍 → 拐弯甩镜 → 仰角跳障碍上摇。关键：动作之间用转场动词衔接。
2. **对话张力**：缓推 + 浅景深 → 缓慢环绕 → 反打焦点。关键：环绕中保持双人在画。
3. **环境互动**：特写触碰 → 急速上摇展现蔓延 → 升降拉高揭示全貌。关键：特效（发光符文、涟漪）与运镜同步。
4. **主观视角切换**：第一人称低头看枪 → 快速抬头 → 切到对手过肩反打。关键：用运动模糊与快速移动模拟"切"。
5. **情绪转变**：缓推雨中蜷缩人物 → 阳光破云 → 随起身转为仰角英雄构图 → 拉远展现景色。关键：光线变化要与构图变化同步。

> 注：原文提醒，"Cut to"（硬切）效果可能需要特定工具支持或分步生成——在 AI 视频工具里，优先用快速移动 / 摇镜模拟切换。

## 四、写作清单

写组合运镜提示词时按此检查：

- [ ] 起幅画面的景别、角度、光线是否明确？
- [ ] 运动动词是否唯一主线（推 / 拉 / 摇 / 移 / 升 / 降 / 环绕）？
- [ ] 主体在运动中发生了什么变化（表情、光线、特效）？
- [ ] 情绪落点是什么（音乐渐强、光线破云、焦点转移）？
- [ ] 是否标注了输入图（Image-to-Video 必填）？
