# 运镜基础认知：镜头、角度、光位、运镜方式与景别

在写任何 AI 视频提示词之前，先要能用准确的术语描述"镜头本身"。本文整理自运镜教学讲义，把基础认知拆成五个维度：镜头类型、摄像机角度、光位方向、运镜方式、景别。

## 一、镜头类型

| 镜头 | 适用场景 |
| --- | --- |
| 广角镜头 | 适用于需要拍摄广阔的场景 |
| 长焦镜头 | 适用于需要远距离拍摄或想要突出主体细节的情况 |
| 超长焦镜头 | 远距离拍摄，并可非常精细地捕捉远处的细节 |
| 变焦镜头 | 可调焦距，提供灵活性，可以从广角到长焦进行拍摄 |
| 定焦镜头 | 焦距固定，提供较高的图像质量和光线透过率 |
| 鱼眼镜头 | 用于创意拍摄，强调景象的扭曲和变化 |
| 固定镜头 | 摄像机机位、角度、焦距等均保持不变，画面稳定，给人以平静客观的感觉 |
| 手持镜头 | 摄像机由手持拍摄，画面会产生抖动，营造出真实、紧张、主观的氛围 |
| 长镜头 | 连续拍摄的一个较长的镜头，能保持时间和空间的连续性，增强故事的真实性 |

其中"固定 / 手持 / 长镜头"描述的是拍摄方式带来的画面气质，写提示词时用它们可以快速定调：客观冷静用固定，纪实紧张用手持，叙事沉浸用长镜头。

## 二、摄像机角度

- **平视角度**：摄像机与被摄对象处于同一水平线上，给人以自然、平等、客观的感觉。
- **仰视角度**：摄像机低于被摄对象向上拍摄，使被摄对象显得高大、威严。
- **俯视角度**：摄像机高于被摄对象向下拍摄，可展示环境全貌，使被摄对象显得渺小无助。
- **倾斜角度**：摄像机倾斜拍摄，使画面产生不稳定感，常用于营造紧张不安、悬疑的氛围。
- **背对视角**：摄像机位于主体的背后，通常用于展示主体朝向或环境。
- **主观视角**：摄像机模拟主角的视角。

## 三、光位方向

| 光位 | 效果 |
| --- | --- |
| 正面光 | 照亮主体的细节，减少阴影，并呈现出明亮、开放的感觉 |
| 侧面光 | 创造明暗对比，突出主体的形状和纹理，常用于塑造立体感 |
| 逆光 | 刻画轮廓效果，使主体在背景上显得更加突出 |
| 底光 | 制造戏剧性的效果，强调主体的高度和轮廓 |
| 上光 | 强调主体的头部或顶部，通常在创造神秘或吓人的效果时使用 |
| 斜上光 | 在主体上部产生一些阴影，同时仍然照亮主体的大部分区域 |
| 背光 | 边缘照明效果，使主体周围产生一道发光的边缘 |

## 四、运镜方式

推、拉、摇、移、升、降六大基础运镜：

- **推**：强调主体的重要性或增强紧张感。
- **拉**：揭示更多的环境或放大场景。
- **摇**：跟踪运动的主体或展示广阔的景象。
- **移**：强调主体的高度或展示上或下方的景象。
- **升**：揭示更高的视角或跟踪主体的垂直运动。
- **降**：展示更低的视角或跟踪主体的垂直运动。

## 五、景别（摄像机与被拍摄主体的距离）

1. **远景**：空旷的大环境。
2. **全景**：远距离广角视图。
3. **中景**：上半身或腰部以上的画面。
4. **特写**：通常聚焦在人物的脸部或某个特定细节上。
5. **大特写**：将焦点集中在极小的细节上。

## 如何组合使用

一条完整的运镜提示词，通常就是这五个维度的组合：**景别 + 角度 + 运镜方式 + 光位 + 镜头类型**。例如"低角度仰拍（角度）+ 中景（景别）+ 缓慢推进（运镜）+ 逆光（光位）+ 浅景深定焦（镜头）"，就是一条经典的英雄登场镜头描述。
